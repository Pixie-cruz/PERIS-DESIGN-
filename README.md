# PERIS DESIGN

A responsive website for **Peris Style Collective**, a personal styling brand.

## Features

- Clean, modern layout that works on phones, tablets and desktop
- Personal styling services presented clearly
- Contact and enquiry forms
- Fast, lightweight single-page site with no frameworks

## Built with

- HTML
- CSS
- JavaScript

## Live site

https://pixie-cruz.github.io/PERIS-DESIGN/

## How to run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
